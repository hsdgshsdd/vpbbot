# ⚡ БЫСТРЫЙ СТАРТ - SakuraVPN Bot в 5 минут

Следуйте этому руководству для быстрого запуска бота!

## Шаг 1️⃣: Подготовка (2 минуты)

### 1.1 Получите необходимые ключи
Смотрите [GET_KEYS.md](GET_KEYS.md) для полного руководства. Кратко:

- **BOT_TOKEN** - получить у [@BotFather](tg://resolve?domain=BotFather)
- **ADMIN_ID** - ваш ID (получить у [@userinfobot](tg://resolve?domain=userinfobot))
- **API параметры** - из вашего Marzneshin сервера

### 1.2 Зависимости
Убедитесь что установлены:
- Python 3.8+
- pip

Проверите:
```bash
python --version
pip --version
```

## Шаг 2️⃣: Установка (2 минуты)

### Самый быстрый способ:

**Windows:**
```bash
quickstart.bat
```

**Linux/Mac:**
```bash
bash quickstart.sh
```

### Или вручную:

```bash
# 1. Копируем пример конфигурации
cp .env.example .env

# 2. Редактируем .env и заполняем параметры
# Откройте .env в любом редакторе и заполните:
# BOT_TOKEN=...
# ADMIN_IDS=...
# API_BASE_URL=...
# и т.д.

# 3. Устанавливаем зависимости
pip install -r requirements.txt

# 4. Запускаем бот
python main.py
```

## Шаг 3️⃣: Проверка (1 минута)

Когда бот запущен, проверьте:

1. В консоли должно быть:
   ```
   🚀 Запуск SakuraVPN Telegram Bot...
   ✅ База данных готова
   ✅ Обработчики зарегистрированы
   🤖 Бот запущен и слушает обновления...
   ```

2. В Telegram найдите своего бота и отправьте `/start`

3. Должно показаться меню (если вы in ADMIN_IDS - админ меню)

## Готово! 🎉

Ваш бот готов к использованию!

## 📱 Тестирование функциональности

### Для обычного пользователя:

## ❌ Если что-то не работает

### Ошибка: "No module named telegram"
```bash
pip install -r requirements.txt
```

### Ошибка: "BOT_TOKEN not set"
1. Откройте .env
2. Убедитесь что BOT_TOKEN заполнен
3. Перезагрузите бот

### Бот не отвечает
1. Проверьте интернет
2. Проверьте что процесс запущен
3. Посмотрите логи ошибок в консоли

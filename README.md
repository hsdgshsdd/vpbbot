# SakuraVPN Telegram Bot 🚀

Полнофункциональный Telegram бот для управления VPN подписками сервиса SakuraVPN на основе Marzneshin API.

## Возможности ✨

### Для обычных пользователей:
- 👤 **Личный кабинет** - просмотр статуса подписки
- 🔑 **Управление ключами** - получение и обновление ключей доступа
- 💳 **Оплата подписок** - выбор и оплата тарифов
- 📋 **Конфигурация** - загрузка конфигураций для разных платформ (Windows, iOS, Android)
- ❓ **Справка** - помощь по использованию VPN

### Для администраторов:
- 👥 **Управление пользователями** - просмотр списка, поиск, добавление
- 📊 **Статистика** - общая информация о подписках и доходах
- 🎁 **Управление сервисами** - добавление и редактирование сервисов
- 📥 **Входы (Inbounds)** - управление входными точками
- ⚙️ **Настройки** - конфигурация и проверка подключения
- 📋 **Логирование** - отслеживание действий администраторов
- 🎛️ **Администраторские команды** - расширенное управление системой

## Требования 📋

- Python 3.8+
- pip
- Telegram Bot Token
- Marzneshin API доступ

## Установка 🔧

### 1. Клонирование репозитория
```bash
cd vpnbot
```

### 2. Создание виртуального окружения (рекомендуется)
```bash
# Windows
python -m venv venv
venv\\Scripts\\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Конфигурация
Скопируйте файл `.env.example` в `.env` и заполните параметры:
```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321

# Marzneshin API Configuration
API_BASE_URL=http://localhost:8000
API_USERNAME=admin
API_PASSWORD=admin

# Bot Configuration
DB_PATH=data/bot.db
DEBUG=True
```

**Где получить параметры:**
- **BOT_TOKEN**: Получить у [@BotFather](https://t.me/botfather) в Telegram
- **ADMIN_IDS**: Ваш Telegram ID (получить у [@userinfobot](https://t.me/userinfobot))
- **API параметры**: Данные вашего Marzneshin сервера

## Функциональность 🎯

### Для пользователей

#### /start
Главное меню бота с основными опциями

#### /account
Просмотр статуса подписки:
- Ваш Telegram ID
- Статус подписки (активна/неактивна)
- Дата истечения
- Инструменты быстрого доступа

#### /update_keys
Управление ключами доступа:
- Просмотр текущего ключа
- Загрузка конфигурации для разных ОС
- Получение нового ключа

#### /payment
Оплата подписки:
- Выбор тарифа (1, 3, 6, 12 месяцев)
- Подтверждение платежа
- Автоматическое создание подписки

#### /help
Справка и FAQ

### Для администраторов

#### /admin
Главное меню администратора с доступом к:
- 👥 Управлению пользователями
- 📊 Статистике
- 🎁 Управлению сервисами
- 📥 Управлению входами
- ⚙️ Настройкам
- 📋 Логам действий

## Интеграция с Marzneshin API 🔗

Бот полностью интегрирован с Marzneshin API для:
- Создания и управления пользователями
- Управления подписками
- Работы с сервисами и входами
- Получения статистики использования

### API Endpoints используемые:
- `POST /api/admins/token` - Получение токена доступа
- `POST /api/users` - Создание пользователя
- `GET /api/users/{username}` - Получение информации пользователя
- `PUT /api/users/{username}` - Изменение пользователя
- `GET /api/services` - Список сервисов
- `POST /api/services` - Создание сервиса

## Система платежей 💳

Текущая версия включает заглушки платежной системы. Для интеграции реальных платежей:

1. Раскомментируйте платежную систему в `src/handlers/user_handlers.py`
2. Добавьте интеграцию с вашей платежной системой (Yandex.Kassa, Stripe и т.д.)
3. Обновите функцию `confirm_payment()` для реальных платежей

## База данных 🗄️

SQLite база данных с таблицами:
- **users** - информация о пользователях и их подписках
- **payments** - история платежей
- **admin_actions** - логирование действий администраторов

## Логирование 📝

Все действия регистрируются в консоль с уровнями:
- INFO - основная информация
- WARNING - предупреждения
- ERROR - ошибки
- DEBUG - отладочная информация (если DEBUG=True)

## Расширение функциональности 🔧

### Добавление новой команды

1. Создайте функцию-обработчик в соответствующем файле:
```python
async def my_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text("Hello!")
```

2. Зарегистрируйте обработчик в `main.py`:
```python
application.add_handler(CommandHandler("mycommand", my_command))
```

### Добавление новой inline кнопки

1. Добавьте обработку в `src/handlers/callback_handler.py`
2. Добавьте кнопку в соответствующий методом `InlineKeyboardBuilder`

## Решение проблем 🐛

### Бот не отвечает
- Проверьте BOT_TOKEN в .env
- Проверьте интернет соединение
- Проверьте логи в консоли

### Ошибка подключения к API
- Проверьте API_BASE_URL, API_USERNAME, API_PASSWORD
- Убедитесь, что Marzneshin сервер запущен
- Проверьте сетевую conectivity

### Ошибка базы данных
- Удалите файл `data/bot.db`
- Перезагрузите бота (он пересоздаст БД)
